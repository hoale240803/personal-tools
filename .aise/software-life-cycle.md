Cột mốc	Đầu vào	Đầu ra
0. Vấn đề	Ý tưởng thô	1 trang: vấn đề, người dùng, chỉ số thành công, ràng buộc (thời gian, tiền)
1. Khám phá	Vấn đề	Sổ lỗi thực tế, danh sách “việc khách cần làm”, bảng so sánh tính năng đối thủ
2. Chốt MVP	Bảng tính năng	Story map, lát cắt MVP, danh sách “không làm”, backlog xếp ưu tiên
3. Đặc tả hành vi	Lát cắt MVP	User story + tiêu chí Given-When-Then, ví dụ luật nghiệp vụ, nháp dữ liệu, bảng thuật ngữ
4. Kiến trúc	Đặc tả	Sơ đồ module và cổng, quyết định kiến trúc (ADR), chiến lược test
5. Chia việc	Đặc tả + kiến trúc	Epic → story → micro-task, mỗi task đủ điều kiện “sẵn sàng làm”
6. Vòng xây dựng	Một micro-task	Code + test + chạy được, qua CI
7. Duyệt	Bản demo	Chủ sản phẩm chấp nhận hoặc từ chối kèm lý do
8. Chạy thử và học
